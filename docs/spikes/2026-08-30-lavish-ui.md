# Lavish for UI/UX stories

**Date:** 2026-08-30  
**Status:** config-driven — default `auto` (UI repos only); not a blocking ship stage  
**Upstream:** https://github.com/kunchenguid/lavish-axi

## Decision

`lavish.enabled`: `auto` | `on` | `off`. `auto` turns on when the repo looks like UI (React/Vue/Next/shadcn `components.json`, or `frontend/` / `web/` / `ui/` with those markers). Override per slug in `lavish.repos`.

Jira + `spec.md` stay the contract. Lavish is an extra visual loop.

Do **not** install `lavish-axi setup hooks`. Do not fail `/dev-loop` ship if Lavish is missing.
