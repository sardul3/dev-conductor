# Spike: Lavish for UI/UX stories

**Date:** 2026-08-30  
**Status:** spike — not a required `/dev-loop` stage  
**Upstream:** https://github.com/kunchenguid/lavish-axi

## Decision

Keep **Jira + markdown `spec.md`** as the requirements and acceptance-criteria loop for every ticket.

For **UI/UX** tickets only, the agent may use Lavish (`npx -y lavish-axi`) so a human can annotate HTML in a local browser instead of pasting screenshots into chat.

Do **not**:

- Add a conductor stage that blocks ship on Lavish
- Install `lavish-axi setup hooks` (SessionStart) by default
- Replace Jira AC with HTML artifacts

## How to try it

```bash
npx -y lavish-axi --help
npx -y lavish-axi playbook plan
npx -y lavish-axi design
```

Skill trigger: `skills/lavish-ui` (description is the trigger). After `./install.sh`, it is copied to `~/.claude/skills/lavish-ui`.

## Exit criteria for a later promote-or-kill

- One real UI story used Lavish without slowing the spec gate
- Artifacts did not become a second source of truth (Jira still matched)
- No desire for always-on hooks

If those fail, delete the skill and this note.
